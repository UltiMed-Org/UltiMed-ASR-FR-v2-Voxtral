# Ten technical French medical sentences, for auditioning a voice on the text it will
# actually have to speak. Hand-picked from the UltiMed v1 corpus as the HARDEST rows it
# contains: these are the highest-whisper-CER sentences of the finished v1 run (CER 0.08
# to 0.12 against a single voice), spread over its four categories so the test covers drug
# brand names, acronym strings, surgical materials and unit-heavy prose rather than one of
# them. FLEURS sentences cannot answer this question: a voice that reads Wikipedia prose
# cleanly can still derail on 'Epidyolex solution buvable' or 'ypT2 N0 R0'.
#
# The last TWO lines are different in kind and were written for this file rather than
# taken from v1: they are ~65 words each, which at the grid's measured 2.15 words/second
# (median over 9396 clean French takes) is about 30 seconds of speech, against ~12 s for
# the ten above. They test stability over length, which is a separate failure from
# mispronunciation: Voxtral degenerates by looping syllables, and a voice can read three
# short sentences perfectly and still lose the plot halfway through a long one.
#
# Their length is pinned by the junk test, so do not lengthen them casually. A take is a
# runaway at RUNAWAY_FACTOR (3.0) x what the voice's own rate predicts, and separately junk
# if it hit the token ceiling, and the sweep caps takes at 1125 tokens = 90 s. At 64 words
# the runaway threshold is 3 x 64 / 2.15 = 89.3 s, which just fits under that cap, so both
# tests still work. At 73 words it is 102 s, past the cap: a degenerate take gets truncated
# at 90 s, measures as healthy, and the voice looks clean precisely because it is broken.
# The ceiling test does still catch it (see `is_junk`), but the runaway margin is gone, so
# 64 words is the ceiling for this file unless the run also raises MAX_TOKENS.
#
# Neither verdict needs the ASR: the tts pass records each take's duration from the wav it
# just wrote, so SCORE=0 keeps the junk net and loses only the WER numbers.
#
# Source: UltiMed-ASR-FR-v1 (CC BY 4.0 subsets) for the first ten, via Claude Code. One
# sentence per line, which is what `sweep.py sentences --corpus --curated` expects.
# `--curated` is required: the default screen rejects every line here, since they all
# carry digits.
